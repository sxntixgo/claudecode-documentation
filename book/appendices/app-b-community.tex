\begin{table}[ht]
\centering
\caption{Plugin marketplaces}
\label{tab:app-marketplaces}
\begin{tabularx}{\textwidth}{llX}
\toprule
\textbf{Name} & \textbf{Add command} & \textbf{Curation} \\
\midrule
\texttt{claude-plugins-official}
  & \emph{always available}
  & Curated by Anthropic. Includes \texttt{superpowers}, \texttt{mcp-server-dev}, and other first-party plugins \\
\texttt{claude-community}
  & \texttt{/plugin marketplace add anthropics/claude-plugins-community}
  & Community submissions reviewed before listing. Pin-commit-SHA distribution \\

\end{tabularx}
\end{table}

Submit a community plugin via the in-app forms at
\url{https://claude.ai/settings/plugins/submit} or
\url{https://platform.claude.com/plugins/submit}. The review pipeline runs
\texttt{claude plugin validate} plus automated safety screening.

\section{Community Skills and Plugins}
\label{app:community-plugins}

\begin{itemize}
  \item \textbf{Superpowers} (\url{https://github.com/obra/superpowers}) —
        production-ready skills bundle covering plan-writing,
        test-driven development, brainstorming, and more. Install via
        \texttt{/plugin install superpowers@claude-plugins-official}.
  \item \textbf{awesome-claude-code}
        (\url{https://github.com/hesreallyhim/awesome-claude-code}) — a
        curated link list of tools, skills, hooks, and articles.
\end{itemize}

\section{Reporting Issues and Feedback}
\label{app:feedback}

\begin{itemize}
  \item \textbf{In a session:} \texttt{/feedback} sends a report
        directly to Anthropic.
  \item \textbf{Bugs in Claude Code itself:}
        \url{https://github.com/anthropics/claude-code/issues}.
  \item \textbf{Security vulnerabilities:} the HackerOne program linked
        from \url{https://code.claude.com/docs/en/security}. Do not
        disclose publicly.
\end{itemize}

\section{Following Anthropic Releases}
\label{app:releases}

Claude Code evolves fast. Two ways to stay current:

\begin{itemize}
  \item Anthropic news: \url{https://www.anthropic.com/news} — model
        announcements, feature launches.
  \item In-session: \texttt{/release-notes} prints recent Claude Code
        changes.
\end{itemize}
