\markboth{Preface}{Preface}

This book is a comprehensive guide to Claude Code, Anthropic's official CLI
for AI-assisted software development. It consolidates the official documentation
into a coherent pedagogical progression, from fundamental concepts to advanced
production workflows.

\medskip\noindent
\textbf{Who This Book Is For.}
Developers at any experience level who want to leverage Claude Code effectively.
Beginners will find a structured path from installation through first projects;
experienced engineers will find deep dives into optimization, security, and
custom tooling.

\medskip\noindent
\textbf{How to Read This Book.}
The four parts follow a deliberate learning arc:
\begin{itemize}
  \item \textbf{Part~I} establishes the conceptual foundation — the plugin
        ecosystem, the Model Context Protocol, and effective prompting.
  \item \textbf{Part~II} covers the four core building blocks — agents, skills,
        slash commands, and model selection.
  \item \textbf{Part~III} introduces advanced configuration and reasoning
        control — thinking modes, context management, hooks, and advanced
        prompting techniques.
  \item \textbf{Part~IV} addresses production concerns: token optimization,
        security, compliance, and real-world project patterns.
\end{itemize}
Two appendices provide reference documentation and community resources. The
glossary and index support quick lookups across the entire book.

\medskip\noindent
\textbf{Per-Chapter References.}
Each chapter ends with a curated reference list. References were verified
against the current Anthropic documentation at the time of writing; URLs were
checked for availability. Entries include official Anthropic guides, the Model
Context Protocol specification, and relevant community resources.

\medskip\noindent
\textbf{Versions and Currency.}
Model names and pricing are verified against the Anthropic documentation as of
\today. Claude Code evolves rapidly; always consult
\url{https://docs.anthropic.com} for the latest information.
